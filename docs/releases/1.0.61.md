# 1.0.61 · 2026-11-10

本次更新主要增加界面字体自定义设置支持，并将默认字体优化为 Windows 自带简体中文字体（微软雅黑 / Microsoft YaHei UI）。

### 界面与字体

- **新增界面字体自定义**：在「设置 → 界面」中新增「界面字体」下拉选择框，支持在 Windows 自带中文字体（微软雅黑、宋体、黑体、楷体、等线）与英文系统字体之间快速切换，设置即时生效无需重启。
- **默认中文字体优化**：默认使用 Windows 自带的高清简体中文字体 `Microsoft YaHei UI`（微软雅黑），全面改善中文文件名、路径、属性和标签文本在各 Windows 版本下的清晰度和排版美观度。
- **字体回退链路增强**：排版引擎优先采用本地系统已安装的标准中文字体，优化字重与回退链。

### 升级说明

- 安装包分为 **Windows 10 / Windows 11 (x64)** 和 **Windows 8.1 兼容版 (x64)**，按需下载安装。
